# hydra-birthday

An invite-only birthday site: guests get personal links that sign their browsers in, a few admins get an admin page. TanStack Start + Convex + shadcn/ui, hosted at https://hydra-birthday.code-bloom.app. `bun install && bun run dev` for local dev; see `CLAUDE.md` for the auth model and how to mint invite links. Pushes to `main` auto-deploy via Vercel.
